Select a layer to edit it, or add a new element from the toolbar.

Drag on the canvas to move (snaps to center). Drag the red handle to resize — always from the element's center, never a corner.

Check 🔒 Lock aspect ratio on a layer (always on for Joystick) to stop it stretching into an ellipse on screen shapes different from this one — or use a PX size instead, which never stretches at all.

Click ⭐ Set as Main or 🏁 Set as Endcard when done — the running game hot-reloads immediately.
Ctrl+Z / Ctrl+Shift+Z — undo / redo
Ctrl+D — duplicate selected
Delete — delete selected
Arrow keys — nudge (+Shift for bigger steps)
Esc — deselect
Double-click a layer name to rename
