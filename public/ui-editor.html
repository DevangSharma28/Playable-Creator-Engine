🔎 Properties
Select a layer to edit it, or press ＋ Insert to add one.

Drag on the canvas to move — it snaps to sibling edges, centers and your own guides. Drag any of the eight handles to resize from the opposite side (Alt resizes about the center, Shift keeps the ratio), or the grip above an element to rotate it.

Drag on empty canvas to marquee-select. Ctrl/Cmd+Click (or Shift+Click) adds to the selection; with several selected you get align, distribute and match-size tools.

Check 🔒 Lock aspect ratio on a layer (always on for Joystick) to stop it stretching into an ellipse on screen shapes different from this one — or use a PX size instead, which scales uniformly and never stretches.

Click ⭐ Main or 🏁 Endcard when done — the running game hot-reloads immediately.
